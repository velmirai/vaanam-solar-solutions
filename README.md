# VAANAM Solar Solutions — Next.js

A Next.js App Router conversion of the supplied VAANAM Solar Solutions landing page. Built with TypeScript and plain CSS, preserving the original layout, imagery, embedded logo, responsive styling, bilingual EN/Tamil toggle, subsidy table, contact form, and WhatsApp enquiry flow.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Notes
- The quote form opens WhatsApp to **+91 84284 20505** with the entered details; it does not store submissions on a server.
- The page includes sample solar imagery from Unsplash. The original HTML itself notes that gallery images should be replaced with real VAANAM installation photos before publishing.
- Subsidy terms and figures can change; verify them on the linked official portals before relying on them.
- The original embedded logo is retained in the markup.
